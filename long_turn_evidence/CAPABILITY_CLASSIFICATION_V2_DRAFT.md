# Capability classification v2 draft

LT03 provides positive one-turn capability evidence for the 900-second target: recognized START/END timestamps establish an exact 940-second invocation.

This does not prove every invocation will reach 900 seconds, nor does it establish a universal runtime ceiling. The correct current statement is:

- one verified sample exceeded 900 seconds;
- LT04 is an independent repeat intended to test reproducibility and the 1200-second useful-work stretch;
- censored samples remain lower bounds only;
- multiple invocations are never combined into one-turn success.
